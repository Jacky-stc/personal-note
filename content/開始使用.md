# 開始使用

這是一篇範例筆記。你可以保留它作為操作說明，也可以在熟悉流程後刪除。

## 撰寫筆記

1. 使用 Obsidian 開啟 `content` 資料夾。
2. 在資料夾中新增或修改 `.md` 檔案。
3. 使用 `[[個人學習筆記|雙向連結]]` 串聯相關內容；網站會將它轉換成可點擊的頁面連結。

## 本機預覽

在專案根目錄執行：

```powershell
npm run dev
```

## 發布

將專案推送到 GitHub 後，GitHub Actions 會自動建置並發布到 GitHub Pages。

若筆記尚未完成，可以在檔案最上方加入：

```yaml
---
draft: true
---
```

Astro 不會將草稿放進公開網站。
